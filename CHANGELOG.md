# Changelog

## 1.0.0 – 2026-11-09

First complete release.

- Battleship game with pygame: fleet setup, battle, result screen
- Four AI levels: Beginner (random), Easy (hunt & target), Medium (neural
  network), Hard (neural network + search)
- Five nations with battleship silhouettes, flags, fire, smoke and sinking
- Shot logs for both sides and an AI heatmap (`H`)
- Reproducible ML pipeline (generate, analyze, train, evaluate), developed
  along CRISP-DM in three iterations
- 59 automated tests, linting and GitHub Actions CI
